## 二、证明与表述

- **定理 1**：推广到任意闭合多边形（与剖分无关），给出更短的证明（鞋带公式是二次型，中点公式精确），并注明虚部就是 ALE 方法中的离散几何守恒律（Thomas–Lombard 1979；Farhat 等 2001）。记号改为 $c_e=\overline{u^{\rm m}_e}q^{\rm m}_e$，消除上横线同时表示平均与共轭的冲突。
- **定理 2**：改名为"离散运动学环量恒等式"，因为它不含动力学。新增推论（离散 Kelvin 定理）：正压无粘时，每步环量漂移 ≤ $\frac{\Delta t^2L}{12}(h^2\|\nabla^2a\|+\Delta t^2\|D_t^2a\|)$，附证明。
- **新增命题（单轴签名）**：签名是充要刻画，即 arg p=0 且 |μ|=tanh(½|lnJ|) 当且仅当 F 为对称阵且有一个特征值等于 1。另注明合并块等于块两端帧之间的直接三点映射。
- **账本**：写明估计量是什么，给出多边形面积的精确二次展开，由此定义非仿射指示量；写明账本在光滑流中只有一阶精度，并给出张量/混合估计。望远相消命题的假设写精确：平面激波、两侧为均匀态、激波速度恒定。
- **Dirac 一节**：恒等式与度量无关，度量只进入 Laplacian 块；写明 M₁ 取 Whitney 质量阵。方差衰减补上前提（ρκ≥0、三角形正定向）。新增边电导 M 矩阵版本及其代价。
- **掺混一节**：κ>0 时 Nanson 分解只是运动学部分；按积分耗散计，拉伸项要计两次（∝ρκλ²/J）；信息极限给出数值（δ/h=1、2、4、8 时误差为 11%、5%、2%、0.7%）。

## 一、账本 v4（`lhd/ledger_v4.py`，`scripts/v8_ledger_v4.py` → `results/res_v8_ledger_v4.json`）

1. **几何窗口检测**
   - 窗口长度取 2–32 帧。只有当窗口内已有热步解释的面积下降不到一半时才使用这个窗口。
   - 只标记承担压缩的那几步，两侧各加标记跨度一半的余量。
   - 推迟上限最多 60 块。
2. **分段加保护的张量增量**
   - 每个锚定段单独判断：拟合要良态，近邻不跨物质界面。
   - 与多边形增量之差：无热步段不超过 0.1，热步段不超过 0.02+2|δ|+3σ̂/h。

- 弧修复在涡核里被误用：加了整环残差下限。

**物理读数**：激波气泡约 37% 的环量是在三角形自己的激波块之外，由波后压力场沉积的。

# v3.2（2026-10-27）：T4 参照问题解决；标定畸变自标定（负结果）

## 1. T4：冲击/光滑拆分与 DNS 的同类比较（已解决）

**新的主参照**：同一物质三角形上的 DNS 速度环量。示踪点上存有速度，采用与位置形式相同的帽形核 ΔΓⁿ = ½(Γₙ₊₁ − Γₙ₋₁)，并按同一组块拆分。它的总量与位置形式相差 0.07%（窄带 0.21%，含数值耗散），所以是最忠实的参照。

**关键发现**：每个保留的块两侧需要各加一个快照的余量（`t4split.split(margin=1)`，现为默认）。原因是捕捉激波有几个网格宽，前沿比星压缩越过检测阈值早约一个快照到达三角形。不加余量时，结果取决于块端点的取法：

| 块余量 | 宽带冲击部分（位置形式 / DNS 速度） |
|---|---|
| 0 | 0.1728 / 0.1612 |
| 1 个快照 | 0.1794 / 0.1786 |
| 2 个快照 | 0.1813 / 0.1808 |

快照间隔加倍（Δt=0.04）只使位置形式改变 0.5%（`scripts/v10b_t4_dt.py`）。

**余量为 1 时与主参照的比较**：六条带上两部分的最大相差为 3%（窄带光滑部分），其余为 0.0%–1.6%。

| 算例 | 冲击 + 光滑（位置形式 / DNS 速度） |
|---|---|
| 激波–气泡 | 0.1794+0.0950 / 0.1786+0.0960 |
| 粘性激波–气泡 | 0.2056+0.0586 / 0.2052+0.0590 |
| RM | 0.0346−0.0043 / 0.0345−0.0043 |

**另外三种以加速度构造的参照**（`scripts/run_sb_accel.py`）：
- 同一三角形上 DNS 加速度 −∇p/ρ(+∇·τ/ρ) 的线积分：逐求解器步积分、帽形核，覆盖无粘和粘性两种情形；
- 逐求解器步积分的斜压力矩；
- 快照采样的力矩。

三者给出的数值把位置形式包在中间，但各自带有由捕捉激波造成的、几个百分点的误差（加速度线积分的总量误差为 1.2%–3.3%）。粘性参照现在包含了粘性项。

## 2. 静态标定畸变的自标定（负结果，`scripts/v13b_selfcal.py`）

**做法**：在星只平移、不变形的段上，实测面积变化应等于畸变场散度 ∇·d 沿轨迹的变化。据此在正则化网格上拟合 ∇·d，用了 13971 个段。

**结果**：
- 这些段方程与真值的相关系数只有 0.56，因为波后流动只沿一个方向平移，且段内仍含真实体积变化。
- 反演会放大误差：校正后为 3.44%/15.4%，校正前为 1.41%/4.4%。用真值校正可达 0.19%/1.5%，说明误差模型本身是对的。
- 结论：只用位置无法去除静态标定畸变，必须在粒子图像处理阶段去除。论文局限一节已写明。
