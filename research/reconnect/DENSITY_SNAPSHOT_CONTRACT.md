## 3. 观测、独立计算和数值计账

逐档以原 m 计算，令 o 为保存 oracle，u 为重构密度，M=Σm：

- `E2=sqrt(Σm(u−o)² / Σm o²)`；分母不使用 std(o)，不使用浓度初始方差。
- `Einf=max |(u−o)/o|`；另报 `Σm(u−o)/M`、最小/最大有符号相对误差、u/o/m 原始极值。
- 三档原生标签各观测同一光滑函数，不把细网格点值合并为粗网格质量平均；报告相邻两档比值和 log2 比值，但不据两次比值宣称一般阶定理。

kernel 独立计算使用旧 `compression_density_audit_core.bin_density` 的周期分箱、显式核式和 math.fsum；不调用生产 cKDTree 邻居表。ledger 用旧独立精确有理数有向扇形/凸性校验，必须得到相同单次舍入值。N64 两字段也只读复核，不替换旧字节。保留旧 `1e-10*max(1,max(abs(u_ind)))` 实现一致性守卫，仅是代数检查，绝不当成物理误差门槛。

令 a 为独立计算的密度，保留以下非负数值指标，不因为较小而置零：

`B2=||u−a||_m/||o||_m`，`Binf=max|(u−a)/o|`。

保存 binary64 输入先转精确有理数计算平方和、分母、偏差和最大值；开方及网格比较分别在80/100位完成，二者的65位报告字符串和决定须一致，否则保存未决并停止。未来代码必须给出这些计算的独立复核，不用 float64 的相消差代替精确矩。生产和独立计算之间的指标是观测到的数值差异，不是连续真解、输入位置、解析 oracle 或库函数误差的严格上界。

每个相邻网格对、每个指标，令 G=E_coarse−E_fine，B=B_coarse+B_fine：G>B 标为 `decrease_larger_than_evaluation_indicator`，G<−B 标为 `increase_larger_than_evaluation_indicator`，其余为 `numerically_unresolved`。无指标被删去，不引入物理“合格百分比”；原标量/H预算完全不参与重判。报告同时明确：这是相对于保存点 oracle 的空间诊断，不是完整连续 PDE 误差认证。解析 oracle 无新的 PDE 参考/时间积分解，不能把不存在的新参考差填入预算，也不能说保存 oracle 完全没有舍入误差。

## 4. 两条需要正视的解析预期

对于本光滑映射、均匀物质标签和固定环，原范围文档的公式给出 ledger 点密度偏差 O(Δ²)，Δ=1/N；这不是任意粒子布局或激波的定理，不把 sinc 因子除掉。

核方法另有明确的一致性警告。在静止均匀周期网格 m=Δ²、h=2Δ 下，令 C2=9/(4π)、φ(q)=(1−q/2)^6(1+3q+35q²/12)，有

`Σ_j m_j W_h(r_ij) = (C2/4) Σ_{k∈Z², |k|<4} φ(|k|/2)`。

右侧与 N 无关（支撑小于半周期）。已有 T1 N32 独立80/100位记录的值为1.0004157504550328，偏差约4.1575e−4；本轮引用该旧结果，不重新求和生成密度。这说明连续核归一化不能保证固定 h/Δ 下的离散一致性。运动非均匀快照的极限偏差不等于该静态数字；四字段实验的目的正是观察其行为。平台、增大或未决均为有效结果，不调 h 倍率以制造下降。
