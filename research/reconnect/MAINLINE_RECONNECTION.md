# LTN主线回接：规范、实现与当前物理断点

2026-10-31。Stage 3仍为 **incomplete**，fluid ORC **关闭**。本轮只推进统一图层接口、一个三节点代数判别及已有流体候选的只读接入审计，未运行新的流体瞬态。

## 1. 本轮完成了什么

原研究主线是：固定身份轨迹与初始质量 → 当前物理交换图 → 时间有序传播 → 实际质量加权掺混 → 经物理验收后才解释动态ORC。早期对话把F/C放入主流程的方案后来已明确修正，不能倒退采用早期草案。

本轮将散落的约定收成可运行的小型 `supplied_graph` 研究接口，位于 `research/reconnect/trajectory_chain.py`。它接收固定身份、位置历史、固定质量、初始质量分数和可选的oracle密度历史；不需要真实物质面、F/C、速度梯度或当前Voronoi单元。调用方另外提供共享非负电导的时间序列。本轮**没有实现由位置/密度自动产生可信物理电导的通用后端**。

用一个预先给定的三节点、不等质量、两时间段交换图验证完整图层流程；另读取原128单元候选的原始Q及其已保存的物理误差，确认它们为何尚不能接入合格的流体传播链。没有对失败的流体候选构造新传播子。

## 3. 最小流程的判别性实验

只使用三节点代数夹具，不称为Becker/DNS或流体PDE算例。质量为[1,2,3] kg，c0=[0,0.2,1]，时间为[0,0.04,0.1] s。给定共享边为(0,1)、(1,2)；两段电导分别为[0.8,0.4]与[0,0.9] kg/s。这些是预设测试值，不是由轨迹反演的物理电导。

三帧位置为[0,0.7,1.5]、[0,1.3,2.0]、[0,1.4,2.2] m。示例当前邻接只允许左端帧间距小于1 m的边，给定电导满足此约束。参考图中的(0,1)仍保留，而第二段实际交换g_01=0，直接展示两图分工。d0(0,2)=1.5 m始终固定，末帧当前距离为2.2 m；不因物质拉开而改写ORC参考分母。该邻居规则仅为夹具约定，不是通用边界/物理近邻算法。

每段按

\[
A_s=(M+\Delta t_sL_s)^{-1}M,\quad c_{s+1}=A_sc_s,\quad P=A_1A_0
\]

传播，不平均生成元替代时序。额外用同一分段常值图的精确矩阵指数，分开识别时间顺序差异和BE误差：

| 判别量 | 结果 |
|---|---:|
| max abs(Q0 Q1−Q1 Q0) | 0.360000/s² |
| 顺序BE与逆序BE的P最大元素差 | 7.78639e−4 |
| 分段精确有序传播与exp(sum dt Q)最大元素差 | 4.15150e−4 |
| BE与分段精确有序传播最大元素差 | 1.05311e−3 |
| P行和残差 | 1.11e−16 |
| m^T P−m^T最大绝对残差 | 0 |
| P c0与逐步标量求解最大差 | 2.78e−17 |

这说明“平均算子替代时序”与“时间离散误差”是两个不同问题；精确指数比较只是有限图上的代数参照，不是连续物理参考解。

相同位置历史下将全部g设为零，P严格为单位阵、质量平均状态不变、I=1、H=0。它验证“纯位置变化不能自行制造图层掺混”；因为本轮没有g(D)物理闭合，不将这一控制包装成通用流体D=0验收。

## 4. 实际标量与能量收支

使用E=0.5 sum m_i(c_i−mean_m c)^2，V=2E/sum m，I=E/E0，H=1−I。夹具末态组分质量仍为3.4 kg，E从0.576666667降至0.533555937 kg，H=0.07475849。这个H只属于测试图，不是可压缩流体混合预测。

逐步恒等式为

\[
E_{s+1}-E_s=-\Delta t_s c_{s+1}^TL_sc_{s+1}
-\tfrac12\|c_{s+1}-c_s\|_M^2.
\]

两段BE附加耗散分别为5.68294e−5、6.98928e−4 kg；恒等式最大残差1.42e−16 kg。端点dt*chi与附加项分别保存，避免把全部离散方差下降归为分子耗散。

P_ij表示初始c_j对末态c_i的贡献。若a=Mc，则列向量组分质量映射为a1=M P M^-1 a0；对应前向行质量核为R=M^-1 P^T M。三者分别命名并验证，保留原始浮点值。

## 5. 接入审计：物理主断点在哪里

本轮对既有128单元矩阵只读，不推进其新瞬态：

| 候选 | 图层代数 | 已保存物理证据 | 接入结论 |
|---|---|---|---|
| 优化诊断图 | 正性、质量和常数检查通过 | 独立冻结制造态变化率相对误差48.8205%，已有物理验收false | 不能凭非负图直接升级流体后端 |
| 混合真实面FV | 原始Q最小非对角为−1.1998523/s | 同态变化率误差20.1298%，原报告正性失败 | 保留本构对照，不能作为Markov传播/ORC后端 |
| 一维普通中心阻力FV | 已有对应算例代数与物理控制 | Becker/接触独立参考及数值误差控制 | 继续作限定范围基线，不冒充二维点轨迹后端 |

主断点因此是：**仍缺一个以允许的轨迹/质量/密度输入构造、兼顾目标PDE精度与非负交换的流体空间后端。** 本轮图层回接让这一缺口可定位，而没有用小图结果绕过验收。禁止将“接口已贯通”写成“流体主线已通过”。
