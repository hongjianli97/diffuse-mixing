# 第三阶段候选路线决定：先声明闭合，再讨论一致性

2026-11-01（UTC）。Stage 3 **incomplete**；fluid ORC **关闭**。

本轮完成上一轮预定的封存证据回查。决定是：**结束共同跨相标量修补；保留普通中心阻力 FV；下一项只研究“点密度重构误差如何进入连续弱形式”这一条件性缺口。当前没有新的通用二维后端获准接纳，也不立即构造新图或运行接触瞬态。**

这不是全部正交换方法的不可能结论。有限输入不能唯一识别任意内部密度，不等于在明示正则性、采样和闭合假设下不能近似。反过来，正性、守恒或一个弱形式误差界也不能自动验收有限节点的物质平均算法。

## 1. 三种障碍的适用范围不同

| 已封存证据 | 已排除或已确认的内容 | 不能据此推断的内容 |
|---|---|---|
| [共同标量证书](CROSS_PHASE_SCALAR_COMPATIBILITY.md) | 固定同相交换、跨相模板、质量及指定二次物质平均时，单个共同跨相标量不能修复两行；局部相对误差有约 20.19665% 的严格正下界 | 所有逐边正交换都不可能；原余弦态或瞬态具有同一个误差下界 |
| [质量平均矩锥](../rebuild/MASS_MOMENT_CONE.md) | 指定模板、几何和精确漂移/二阶矩方程下，没有非负解；协方差差项不能省略 | 允许受控矩缺陷、不同离散族或联合细化的全部正方法均不收敛 |
| [共享交换证书](../rebuild/SHARED_EXCHANGE.md) | 指定全内点约束与共享图不可行；已有行级漂移障碍，不能只归咎于共享对称性 | 任何网格、任何共享正电导都不可行 |
| [密度本构可辨识性](CONTACT_CONSTITUTIVE_REVIEW.md) | 同点、同点密度、同质量和同平均初场可有不同沿段阻力；需要额外先验才能闭合 | 固定正则性类内的近似或收敛不可能；反例是两套完整 NSF 热力学解 |
| [密度—几何审查](../rebuild/DENSITY_GEOMETRY.md) | 一般有限点轨迹不能唯一识别真实物质体积；m/rho(point) 不是自动识别出的真实体积 | 由点构造的求积规则在任何有条件的模型类中都不可用 |

矩锥、共享图、Becker 密度几何和二维周期接触来自不同控制问题。它们在这里用于限定声明范围，**不把误差百分比跨问题排序或分配因果份额**。本轮只读取原证据，没有重解 LP、复跑证明或重算物理案例。

## 2. 路线取舍

| 路线 | 决定及原因 |
|---|---|
| 普通中心阻力物质 FV | 保留既有一维基线。其真实物质端点/阻力信息属于该基准分支的输入，不能升级成通用 LTN 的必要输入。质量平均阻力通量继续是实验对照。 |
| 当前共同跨相标量修补 | 关闭；不再试不同标量、修对角或按二次探针拟合权重。 |
| 指定固定图的全部精确矩拟合 | 不重复运行；已有证书只关闭相应方程组。后续若采用近似矩，必须另外给出缺陷控制，不能删掉协方差项。 |
| 已存真实面混合 FV | 不接纳为 Markov 后端；原生成元有显著负非对角。也不把它当作普通中心阻力 FV 的失败。 |
| 完整密度沿段阻力 | 保留额外信息 oracle。它已改善原连续余弦态响应，但二阶界面和质量平均投影仍有缺陷。 |
| 点密度重构 + 逐边路径阻力 | **选作有条件的分析路线，尚非接纳候选。** 使用下述显式输入契约；先界定密度重构在弱形式中的影响，不立刻再跑图。 |
| 更丰富的物质平均正交换闭合 | 仍开放；当前没有足以编码为生产后端的公式、求积误差界或瞬态证据。不得以“尚未排除”写成“已经可行”。 |

原主线 `supplied_graph` 接口和有限时间传播的代数能力保留；当前断点仍是从允许的点输入获得**物理可信的正共享交换**，不是图接口缺失。参见[主线回接](MAINLINE_RECONNECTION.md)。

## 3. 下一分析路线的输入与闭合

完整契约见 [CONDITIONAL_DENSITY_CLOSURE.md](CONDITIONAL_DENSITY_CLOSURE.md)，机器可读决定见 `runs/reconnect-route-decision/route-decision.json`。

状态始终为固定身份物质单元的质量平均：

\[
m_i=\int_{K_i(t)}\rho\,dV,\qquad
\bar c_i=\frac{1}{m_i}\int_{K_i(t)}\rho c\,dV.
\]

候选可读固定身份、冻结位置/轨迹、固定 m、给定正点密度、常数 D 和周期边界元数据。二维单位厚度 b=1 m；不读取真实面、真实物质邻接、F/C、速度梯度、参考浓度或 PDE 变化率来构造边。

声明一个参数无关的空间闭合：以周期欧氏最近节点的给定密度定义 `rho_hat(x)`，等距时按固定身份确定值。最近点分区**只是密度插值分区**，不是物质单元，不用其面积替换 m/rho，也不宣称它识别了真实几何。

若以后构造逐边系数，其定义固定为

\[
K_{ij}^{\rm rec}=\left[\int_0^1
\frac{d\theta}{D\,\hat\rho(x_i+\theta d_{ij})}\right]^{-1},\qquad
g_{ij}=2 A_i^q A_j^q b K_{ij}^{\rm rec}B_h(|d_{ij}|),\qquad
A_i^q=\frac{m_i}{\rho_i b}.
\]

这里 d 是支撑内唯一的最小镜像位移，原 B_h、因子 2 和支撑均保留。正性和对称性来自定义，尚未数值实现或检验；D=0 应直接给零交换。`A^q` 仍只是求积面积。插值密度的空间积分与固定总质量可以不一致，**不能重归一化任一者来制造一致**。

这条路线的额外先验必须明说：密度有统一正下界和上界、相内有控制的光滑性、界面几何有管状邻域体积控制，采样有填充距离界；将来连接物质平均离散时还需真实代表单元直径/投影误差及质量求积缺陷的条件。它们是有待证明或由指定测试背景保证的模型假设，不是有限点数据已经验证出的事实，更不是新增真实面输入。

## 4. 为何先分析，而不是立刻新跑一次接触图

[完整密度二阶审查](ORACLE_INTERFACE_SECOND_ORDER.md)已经给出同一径向路径核的界面曲率偏差；即使 rho_hat 恰好等于真实 rho，该偏差仍在。密度重构不能被描述为二次响应的局部修复。

[质量平均投影预算](MASS_AVERAGE_PROJECTION_WEAK_BUDGET.md)又说明，理想单元积分与分片常数状态闭合不是同一件事。其充分条件中的 Delta/h 控制不能凭 m/rho(point) 直接宣称成立。[原比例理想行](IDEAL_MATERIAL_ROW_RESPONSE.md)和[缓存点行](SAVED_POINT_ROW_COMPARISON.md)还展示过误差抵消，故一个较小总误差不能替代分项一致性说明。

因此，本轮不预订新的密度接触图、参数点或时间扫描。已知强局部二阶反例不会因为换成最近点密度而消失；弱形式可能仍有条件成立，但必须明确它是不同的数学声明，不把弱结果当作强局部通过。

## 5. 已预先限定的下一项工作

**只补连续弱双线性型的密度重构扰动估计。** 固定原周期域、D、B_h、单位厚度和两个不随 h 改变的全局 Lipschitz 标量/测试函数，比较使用 rho_hat 和完整 rho 的两个连续路径核。分析密度误差如何进入对称交换双线性型，而不是直接比较不同密度分母下的节点生成元。

下一轮需要：

1. 明确所用密度正界、界面/采样假设和常数，审查能否用逆扩散系数的 L1 误差控制双线性型差，并且常数不随 h 发散。该估计**本轮尚未证明**。
2. 对明示的分片光滑密度类，说明最近点重构的 L1 误差需要哪些填充距离和界面管状体积条件；不能从有限点的唯一识别性反推这些条件。
3. 引用既有完整密度弱预算与质量投影预算，不重复证明；明确尚缺的节点求积项、有限物质平均连接和演化稳定性，不能把连续密度估计写成完整离散收敛或瞬态验收。

若估计必须额外读取真实面/F/C、调整 rho 或质量、或让测试函数随 h 集中到界面才能成立，保留失败条件，不改契约来制造结论。这里允许引用不可观测真场来证明条件性定理；不允许把真场作为候选运行时输入。

下一轮仍不构图、解 LP、积分新算子、运行流体/参考瞬态或全矩阵扫描。完成该缺口后，才根据剩余求积/投影障碍决定是否值得实现；不自动进入新版本、PDF 或 ORC。
