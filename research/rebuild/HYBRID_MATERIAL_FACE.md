# 同一零通量制造态上的真实面混合有限体积基线

日期：2026-10-31。第三阶段物理验收仍为 **incomplete**，fluid ORC **关闭**。

本轮实现一个由本构能量和真实共享面直接定义的混合有限体积基线。相同128个固定物质单元、相同冻结时刻和相同独立制造态上，相对质量加权瞬时变化率误差为 **20.1298%**，保存的优化诊断图为 **48.8205%**。新基线有唯一原生共享面通量，其内面通量密度相对误差为 **24.2194%**。它守恒并满足加权能量耗散，但存在约 **−1.19985/s** 的非对角元，正性失败。该算子不升级为物理后端，不用于fluid ORC，也不据此推进新瞬态或宣布空间收敛。

## 1. 固定输入与实验范围

输入为 `runs/rebuild-stage3-noflux-probe/` 中已保存并核验的NPZ；运行前验证其384项科学哈希。Becker参数仍为delta=0.08、D=0.02、T=0.1。本轮只在t=0.05冻结一次：32个流向物质列、4个横向单元，共128个物质单元；真实拓扑为165个顶点、292个面，其中220个内面、72个外面。横向剪切为0.6，刚体转角为pi/6。原64单元数据及其一次横向二等分的128单元数据均不改。

物质状态始终是

\[
m_K=\int_{K(t)}\rho\,dV,\qquad
\bar c_K=\frac{1}{m_K}\int_{K(t)}\rho c\,dV.
\]

保留固定质量、真实四边形、真实质量质心及原始c0。当前探针是独立、有界、外边界上完整梯度为零的双四次制造场，沿用上一轮保存的真实质量平均与物理面通量/体积分参考。它是同一算子的诊断输入，未替换原始c0。制造流为满足连续性定义的运动学基准，不称为未受迫二维Navier–Stokes解或DNS。

未重拟合优化图、未扫描网格或参数、未裁剪、未重归一化，未修改物理rho/D、F/C或验收阈值。本轮误差均为冻结瞬时变化率及面通量误差，不能与历史T=0.1浓度误差混用。旧v0.8.0及其历史NPZ仍未恢复。

## 2. 先定义本构离散，再计算共享通量

单元未知量为质量平均，另为每个真实面引入一个无质量的共享迹值lambda_e。取真实体积V_K、真实质量质心b_K、面面积A_e、面几何中点x_e及单元外法向n_Ke。二维单元按单位厚度计量。

本轮明确采用单元常值系数闭合

\[
\bar\rho_K=m_K/V_K,\qquad \kappa_K=D\bar\rho_K.
\]

这是对变化rho的离散投影，独立参考中的实际rho没有改变。系数投影误差与通量重构误差本轮尚未分离；不得将结果称为变密度本构的精确离散。

令d_Ke=(x_e−b_K)·n_Ke>0，定义

\[
G_K=\frac{1}{V_K}\sum_{e\subset\partial K} A_e n_{Ke}(\lambda_e-\bar c_K),
\quad R_{Ke}=\lambda_e-\bar c_K-(x_e-b_K)\cdot G_K,
\]

\[
\Phi_K=\frac{\kappa_K}{2}\left[V_K|G_K|^2+
\sum_{e\subset\partial K}\frac{A_e}{d_{Ke}}R_{Ke}^2\right].
\]

稳定项乘子在查看探针结果之前固定为1；面积、距离和系数只由物理输入与真实几何决定，无探针拟合。b_K位于真实单元内部；不满足时直接报错，不回退到轨迹点或修复距离。

外向通量定义为q_Ke=−partial Phi_K/partial lambda_e。内部共享迹的平衡方程为q_Ke+q_Le=0；外面直接给定外向物理通量h_e=0。这里没有把边界迹设为已知浓度，也没有事后将计算的边界通量写零。

将局部二次型组装为Hcc、Hcf、Hfc、Hff。对零边界通量，lambda=−Hff^−1 Hfc c，凝聚矩阵

\[
L=H_{cc}-H_{cf}H_{ff}^{-1}H_{fc},\qquad
Q=-\operatorname{diag}(m)^{-1}L.
\]

单元方程m_K d cbar_K/dt=−sum_e q_Ke。规范面法向与已保存参考一致；内部面选择正关联侧的原生通量，并独立检查另一侧的相反通量，不将两侧平均来掩盖残差。所有矩阵保留原始浮点值，不作事后对称化或非负化。D=0有显式零扩散分支，面迹此时不被任意指定为唯一解。

该构造在正交两单元情况下退化为普通中心调和阻力通量。在常系数、匹配物理Neumann边界的线性场上，质量平均等于场在真实质量质心的值，G精确、R为零、原生面通量精确。单元系数不同时不宣称任意全局线性场具有连续通量。

## 3. 同一保存制造态的结果

设r_ref为保存的物理面散度变化率，r=Q cbar。对集合S，统一使用

\[
E_S=\frac{[\sum_{K\in S}m_K(r_K-r_{ref,K})^2]^{1/2}}
{[\sum_{K\in S}m_K r_{ref,K}^2]^{1/2}}.
\]

| 范围 | 保存的优化诊断图 | 本轮真实面混合FV |
|---|---:|---:|
| 全部128单元 | 48.8205% | 20.1298% |
| 60个内部单元 | 27.3744% | 16.6739% |
| 68个边界单元 | 70.5088% | 24.6302% |

全部单元的质量加权变化率RMS误差为0.00999127/s，最大绝对误差0.0644795/s。准确性改善来自本轮本构离散的直接结果，未为降低探针误差调节稳定项。

新FV有原生物理面通量，因而可直接计算

\[
E_q=\left[\frac{\sum_{e\;internal}(q_e-q_{ref,e})^2/A_e}
{\sum_{e\;internal}q_{ref,e}^2/A_e}\right]^{1/2}=24.2194\%.
\]

这是以面积加权的法向通量密度L2误差。内面最大通量绝对误差0.00202780 kg/s。原优化图没有唯一到真实面通量的映射，继续只比较其变化率，不给它补造面通量误差。

独立参考的面散度/体积分变化率差为1.39e−16/s（上一轮已保存）；本轮FV变化率与其自身原生面散度差为8.24e−14/s。上述20%/24%误差远大于这些数值核对残差，但这只排除了该核对误差的影响，不证明网格足够、系数闭合足够或瞬态已通过。未运行时间积分，因而没有新增时间离散误差结论。

## 4. 守恒与能量成立，正性仍失败

| 原始算子审计量 | 数值 |
|---|---:|
| max abs(Q 1) | 9.24e−14/s |
| max abs(m^T Q) | 2.19e−15 |
| max abs(L−L^T) | 5.64e−16 |
| 对称部分−L的最大特征值，仅作审计 | 1.97e−16 |
| 共享内面两侧通量算子不平衡最大值 | 1.17e−15 |
| 原始计算的外边界通量最大绝对值 | 8.56e−17 kg/s |
| 原始Q最小非对角元 | **−1.19985230/s** |

正半定二次型及共享面平衡解释了守恒和质量加权能量耗散；它们不保证Q为Metzler矩阵。按保存的0起始单元编号，令c_93=1、其余单元为0，则

\[
c_{97}=0,\qquad (Q c)_{97}=Q_{97,93}=-1.19985230/s<0.
\]

线性自治系统解在t=0的导数已指向负半轴，因此该连续时间算子不保正。这是原生面通量散度也能复核的基向量反例，不是某种时间步导致的伪负值。本轮不运行该反例的时间推进，不裁剪矩阵，不改稳定项来消除负元。

结论限于本轮具体构造；不宣称所有混合有限体积、所有正系数方法或所有网格均不可能成功。
