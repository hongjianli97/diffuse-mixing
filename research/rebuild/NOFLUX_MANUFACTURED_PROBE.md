# 第三阶段：独立零通量制造态的瞬时物理检验

日期：2026-10-31。Stage 3 **incomplete**，fluid ORC **关闭**。

在原128单元及未修改的矩预算诊断图上，只检查一个独立于优化目标、满足真实外边界零通量的光滑有界标量场。图的质量加权相对**瞬时变化率**误差为 **48.82%**：内点27.37%，边界70.51%。真实共享面通量与独立体积分的变化率差约 `1.39e-16 s^-1`，远小于观察到的误差。

这组原始诊断权重不应升级为物理扩散后端。结论针对这个保存的非唯一见证和单个冻结制造态，不是所有正性共享图的不可能性证明，也不是原c0在T=0.1的终态误差。

## 1. 预先固定的制造态与真实零通量边界

仍使用给定Becker旋转/剪切连续性基准的 `t=0.05 s,delta=0.08,D=0.02`，原64单元基准及派生128分区、质量、c0、图权重和诊断Q均不改变。没有重新优化权重、拟合F/C、调振幅/形状、修改阈值或进行时间推进。

在给定运动的坐标中，物理位置为

\[
Y=R\begin{pmatrix}\xi+k\eta\\\eta\end{pmatrix}+s,
\qquad k=0.6,
\quad \xi\in[\xi_L,\xi_R],\quad\eta\in[-0.5,0.5].
\]

xi_L/R由原物质端面的真实位置给定。固定场为

\[
B(u)=16u^2(1-u)^2,\quad
u=(\xi-\xi_L)/(\xi_R-\xi_L),\quad v=\eta+0.5,
\]
\[
c=0.5+0.25 B(u)B(v).
\]

该场在整个域内为 `[0.5,0.75]`。B与B'在0、1处都为零，所以每条外边界上**完整梯度为零**；这保证实际旋转、非正交物理法向上的Neumann通量也为零，不是仅令某个坐标导数为零。

这是一个冻结时刻的合法标量状态及其瞬时扩散作用，不宣称该空间表达式构成原运动下的完整时变无外力解。流动仍是给定的二维连续性基准，不是二维无外力NS/DNS验收。

## 2. 状态使用真实物质单元质量平均

初值文件中的原c0单独保存，此制造态不替换它。新探针状态始终是

\[
\bar c_i=\frac1{m_i}\int_{K_i}\rho c\,dV.
\]

利用已知真实质量坐标dmu及横向均匀性，分别对流向、横向做乘积积分：

\[
\bar c_{ij}=0.5+0.25\langle B(u(X_B(\mu,t)))\rangle_{d\mu,i}
\langle B(v)\rangle_{d\eta,j}.
\]

常数项按真实质量恒等式积分，横向四次项用三点Gauss精确积分，流向用32/64点控制。另在物理四边形上直接积分rho c并除以**未修改的固定m**作独立核对。

| 平均状态检查 | 原始结果 |
|---|---:|
| 质量坐标平均32/64点最大差 | 1.12e-16 |
| 质量坐标平均与直接密度积分最大差 | 3.67e-15 |
| 密度积分质量与固定m最大相对差 | 6.00e-15 |
| 单元质量平均范围 | [0.5002951522, 0.7113584987] |
| 质量平均与质量质心点值最大差 | 0.0083680635 |

因此不能将状态换成轨迹点、几何中心或质量质心点值。没有为让积分质量吻合而重标定密度或平均状态。

## 3. 真实共享面与独立体积参照

从继承的逻辑顶点身份构造冻结拓扑：165顶点、292条唯一真实边，其中220内部边、72外边。共用顶点坐标必须逐值一致，否则直接拒绝，不做坐标取整、吸附或平均。

规范有向物理面通量为

\[
q_e=-D\int_e\rho\nabla c\cdot n_e\,dS,\qquad
r_i^{face}=-\frac1{m_i}\sum_e C_{ie}q_e.
\]

每条内部边只积分一次、两侧反号。外边界保留直接算得的原始通量，没有强制写成数值零。

独立体积分使用解析多项式导数及Becker密度梯度。在去掉刚体旋转的物理坐标中，记r=partial_xi log(rho)，则

\[
\mathcal Lc=D\{(1+k^2)c_{\xi\xi}-2k c_{\xi\eta}+c_{\eta\eta}
+r[(1+k^2)c_\xi-kc_\eta]\},
\quad
r_i^{vol}=m_i^{-1}\int_{K_i}\rho\mathcal Lc\,dV.
\]

这正是固定物质质量平均在所选状态下的扩散变化率；不把空间多项式本身的显式时间导数当参考。

| 独立物理参照控制 | 最大绝对值 |
|---|---:|
| 面变化率32/64点之差 | 1.05e-16 s^-1 |
| 体变化率32/64点之差 | 2.78e-17 s^-1 |
| 面通量散度与体积分变化率之差 | 1.39e-16 s^-1 |
| 平均状态求积差导致的图变化率差 | 2.41e-16 s^-1 |
| 外边界原始单面通量 | 2.82e-18 kg/s |
| 物理变化率全域质量总量 | 1.48e-17 kg/s |
| 物理变化率与外边界总通量账本残差 | 3.91e-18 kg/s |
| 图变化率全域质量总量 | 1.91e-17 kg/s |

这些是独立数值交叉控制，不是严格区间舍入界；它们足以区分本轮的大幅差异，不需要增加时间步扫描，因为本轮没有离散时间推进。

## 4. 原始诊断图的实际瞬时作用

直接使用保存的原始 `Q` 计算 `r_graph=Q*cbar`，未使用预算存在性证书中的假想修正权重。比较量明确为

\[
E_{rate}=\frac{\sqrt{\sum_i m_i(r_i^{graph}-r_i^{face})^2}}
{\sqrt{\sum_i m_i(r_i^{face})^2}}.
\]

分组时只在对应组内求和，各组分母不同。该指标衡量瞬时变化率，不是以前的浓度终态误差，也不是1.688178%的二阶矩分量预算。

| 单元组 | 相对质量加权变化率误差 | 质量加权RMS误差，s^-1 | 最大绝对误差，s^-1 |
|---|---:|---:|---:|
| 全部128单元 | 48.8205% | 0.0242317 | 0.1485804 |
| 60个内点 | 27.3744% | 0.0155400 | 0.0320627 |
| 68个边界单元 | 70.5088% | 0.0298662 | 0.1485804 |

守恒和二次矩包络不能控制这个更高阶光滑场的误差。本轮没有用制造态重新拟合权重以改善结果。

|---:|---:|---:|---:|
| 69 | 2 | +0.02650518 | 0 |

外边界零通量只消除外侧交换，不会把边界物质单元内部面的扩散率置零；这些非零物理参照不违反边界条件。这些单元只贡献全域平方质量加权误差的约8.366%。更直接地，上一轮372个未识别点对只连接边界单元；任何仅改变这些权重的补全都不改变内点行，因此无法改善当前27.37%的内点误差。该陈述不排除重新设计完整通量方法，但不支持只修孤点后宣布准确。

## 5. 没有补造图的物理面通量

本轮逐面计算的是物理参考通量，图仍只提供点对交换及单元散度。没有将长边图流任意分配给真实面，也没有选一个最小范数面流来冒充物理闭合。

在固定外通量后，220个内部面通量受连通128单元的127个独立散度约束，尚有 **93维循环自由度**。新增四单元循环负对照明确给出非零面流、零单元散度。因此即使某个图恰好匹配所有单元变化率，也不能直接宣称真实逐面通量准确；本轮也没有给出图的逐面误差百分比。
