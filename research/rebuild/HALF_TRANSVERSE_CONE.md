## 1. 唯一改动：明确的物质子单元对照

沿用 [上轮矩锥数据](../../runs/rebuild-stage3-mass-cone/) 的 `t=0.05 s`、Becker参数 `delta=0.08,D=0.02`、32个物质列、真实质量质心、流向质量平均/方差和五个物理目标。只做一次h=0.25m的对照，没有搜索其他间距、流向邻域或求解器容差。

每个原物质四边形沿横向物质标签二等分，得到单独保存的128个冻结子单元。等质量划分和初值复制依赖两个分别声明的基准事实：密度沿物质横向标签均匀，原初始标量只依赖流向质量标签。因此

\[
m_{i,-}=m_{i,+}=m_i/2,\qquad
\bar c_{0,i,-}=\bar c_{0,i,+}=\bar c_{0,i}.
\]

这是已知场上的物质分割，不是调整原m、重归一化密度或从一般父单元平均值恢复未知子结构。实现要求显式声明这两个条件；缺少初始标量横向均匀条件时会拒绝复制c0。

子单元按`2*parent_index+half_slot`保存，原单元16的上半单元索引为33，位于四行中的第1行（从0起计数）。派生128单元中有60个真正的内点；该单元及其第10至22列、相对行-1/0/+1的38个邻居均在原域内。**本轮没有虚拟外侧行。** 其他行和边界没有被标记为已完成算子验收。

程序：[transverse_partition.py](transverse_partition.py)、[half_cone_study.py](half_cone_study.py)。保存完整父子身份、冻结子四边形、固定子质量/初值、质心和协方差；没有写回或替换原几何记录。

## 2. 回聚合保留真实质量平均与二次矩

设父单元横向边向量为w，流向单位向量为e，流向质量方差为v_xi。子质量质心为

\[
b_\pm=b\pm w/4.
\]

父、子中心协方差为

\[
S_{parent}=v_\xi ee^T+ww^T/12,\qquad
S_{child}=v_\xi ee^T+ww^T/48.
\]

子单元回聚合必须包含质心之间的协方差：

\[
S_{parent}=\tfrac12\sum_{\pm}
\{S_{child}+(b_\pm-b)(b_\pm-b)^T\}.
\]

因此线性、二次质量平均能回聚合为原父值；只平均两个子协方差会丢失必要项。没有以几何中心或轨迹点代替质量质心。

| 对全部父/子单元的检查 | 最大原始残差 |
|---|---:|
| 子质量之和减原质量 | 0 |
| 子初始组分质量之和减原组分质量 | 0 |
| 子质量质心回聚合 | 2.78e-17 m |
| 二次质量平均回聚合 | 6.67e-16（按所存五个多项式分量） |
| 全协方差公式 | 3.47e-18 m² |
| 子面积之和减父面积 | 4.17e-17 m² |
| 真实密度独立积分的子质量相对差 | 6.00e-15 |

独立密度积分直接除以已知固定物理子质量，没有用计算到的积分质量重新标定状态。32/64点密度积分的质量相对差约 `3.34e-16`；五个多项式质量平均最大差约 `4.45e-15`。这些是数值控制，不是严格舍入误差界。

## 4. 五个完整矩的非负单行见证

新支持保留质量平均协方差差值，满足

\[
\sum_jr_{ij}d_{ij}=\beta_i,\qquad
\sum_jr_{ij}(d_{ij}d_{ij}^T+S_j-S_i)=\Gamma_i,\qquad r_{ij}\ge0.
\]

分析坐标仅去掉给定运动的刚体旋转和平移，保留真实物理剪切。构造的38个邻居与实际冻结子质心逐项对应，没有拟合F/C。
