# 第三阶段：FV 的非 oracle 平均密度与物质体积辨识

日期：2026-10-31。Stage 3 **incomplete**，fluid ORC **关闭**。本轮按上轮决定保留普通中心阻力 FV，冻结核方法扩展，转向密度与几何输入。

同一 Becker 算例得到明确区别：真实物质面给出的 `m/V` 是精确单元平均密度，但以片常值使用它仍有系数闭合误差；粒子中点双体积则可能根本不是原物质单元。本轮双体积最大偏差约 15.3%，其中实际流体质量与固定账本质量最大偏差约 15.4%，尽管所有固定质量标量求解都守恒。另构造了相同点轨迹、不同物质体积的运动学反例，说明缺少物质边界信息时的可识别性限制。

这里复用的是**独立重建**的 Becker 数据，不是恢复的旧 v0.8.0；不能与尚未核对的旧原型数字拼接。

## 1. 输入和状态保持不变

复用 `runs/rebuild-stage3-space/inputs-cells32.npz` 的质量边界、32 个固定质量、精确初始质量平均与独立参考投影。物理参数仍为 `delta=0.08`（速度10%–90%宽度）、Mach=2、D=0.02、T=0.1，初始物质标签 `[-1,1]`，物质端点标量无通量。

状态为同一组真实物质单元的质量平均：

\[
m_i=\int_{K_i(t)}\rho dx,\qquad
\bar c_i=m_i^{-1}\int_{K_i(t)}\rho cdx.
\]

oracle 基线的4096/8192步解、8192单元/8192步独立参考及其已有空间/时间细化投影全部读取旧 NPZ，并验证 SHA-256。没有重算参考来改变比较对象。

新增候选只从固定质量和位置计算密度，不查询未来点密度。**位置输入仍是解析 Becker 合成数据**，包含全部真实物质面的轨迹、每个初始单元一个中点粒子的轨迹和两个端点轨迹。因此真实面方案已经获得额外几何信息，不能宣称只靠内部点云恢复了物质边界。

## 2. 真物质面与动态双单元

真实物质面记为 `b_i(t)`，

\[
V_i=b_{i+1}-b_i,\qquad \bar\rho_i=m_i/V_i.
\]

这是物质平均密度的定义，不需要拟合 F、C、局部速度梯度或热力学假设。但它只给出平均密度，并不完整确定单元内部的 `1/(ρD)` 分布。

对初始均匀单元的中点粒子 `X_i(t)`，另定义内部双面

\[
\widehat b_i(t)=[X_{i-1}(t)+X_i(t)]/2,
\]

两端采用相同的真实物质边界轨迹。由此得到 `Vhat_i` 和 `rhohat_i=m_i/Vhat_i`。初始时双面与真实面相差仅 `6.67e-16`；非仿射压缩后不再重合。仿射运动下两者相同的控制已验证。

密度模块 [fv_density_geometry.py](fv_density_geometry.py) 只做上述几何和正性验证。位置次序丢失、重复点、非正体积或非有限密度直接拒绝，没有保持旧值、填零或修补。

## 3. 一个约定顺序的四项对照

保持同一普通几何中点阻力 FV，只有以下四个设置：

| 记号 | 几何 | 密度/阻力 | 解释 |
|---|---|---|---|
| A | 真实物质面 | 连续 oracle 密度的中心间阻力积分 | 复用的原基线 |
| B | 真实物质面 | `m/V` 单元平均，片常值阻力 | 新平均密度闭合 |
| C | 真实物质面 | `m/Vhat`，片常值阻力 | 仅扰动密度的诊断混合项 |
| D | 双面 | `m/Vhat`，片常值阻力 | 非物质几何负对照 |

C 的密度与真实体积不满足逐单元 `ρV=m`，只是隔离密度误差的混合诊断；D 虽代数满足 `rhohat Vhat=m`，双面仍不是原物质面的轨迹。C/D 均不作为可接受的真实物质 FV 后端。

片常值密度的共享面导通率为

\[
g_{i,i+1}=\left[\frac{V_i}{2\rho_iD}
                     +\frac{V_{i+1}}{2\rho_{i+1}D}\right]^{-1}.
\]

对于 B，每个半单元阻力为 `V_i²/(2m_iD)`。若 `r_i=Vhat_i/V_i`，C 的半阻力相对 B 乘以 r_i，D 则乘以 r_i²。因此体积误差既进入密度，又进入通量长度；两个影响不能混为一个密度点值误差。公式本身不涉及权重重归一化。

## 4. 几何和真实质量审计

全8193个位置帧验证体积正性，另固定保存129个均匀时刻作真实流体质量和面通量审计：

| 量 | 最大值 |
|---|---:|
| 双体积相对真实物质体积偏差，全帧 | 15.2943% |
| `m/Vhat` 相对真实物质平均密度偏差，全帧 | 13.2654% |
| 双单元中实际流体质量相对固定 m 偏差，129帧 | 15.3860% |
| 双面位置相对真实物质面偏差，全帧 | 0.00340250 |
| 双单元真实流体质量变化率绝对值，129帧 | 0.434383 |

这里比较的是不同但清楚定义的量，不将它们都称作同一个“密度误差”。真实面速度与流体速度的独立中心时间差分核对最大差约 `5.56e-9`；双面的滑移产生实际质量通量。

具体用 Reynolds 输运式检查：

\[
\frac{d}{dt}\int_{\widehat K_i(t)}\rho dx
=\rho(u-w)_{\widehat b_i}-\rho(u-w)_{\widehat b_{i+1}},
\]

其中双面速度 w 由相邻粒子速度平均得到。双单元实际流体质量还由独立质量坐标反演计算。末时刻第16号（从0编号）单元：固定质量 `0.07295083274`，双单元内实际质量 `0.08127515427`；独立物理空间密度积分与后者相差 `1.12e-16`。

因此固定 M 的标量总量守恒，不能证明双单元中的流体质量仍是 m。D 的标量代数检查通过不修复这个几何含义错误。

## 6. 相同点轨迹也不能唯一确定物质体积

对初始单元宽度 `da=1/16`、内部中点 a_i，构造

\[
\widetilde X(a,t)=X(a,t)+0.02\,da\,\frac tT
 (1-a^2)\cos\!\left[\pi(a+1)/da\right].
\]

扰动在所有内部中点和两端点恒为零，且 t=0 时整张映射不变。因此两个运动学输运具有相同的全部点轨迹、点速度、端点轨迹和初始物质质量。

扰动导数绝对值上界小于 `0.02 da(2+π/da)`，Becker基映射导数下界为 `u2/u1=0.375`，故替代映射仍严格单调，下界约 **0.309668**。两者都是合法的正体积运动学映射；将初始质量推前即可分别满足连续性方程。

计算中末时刻点轨迹差仅 `3.47e-18`，但真实物质体积最大相对差约 **10.2631%**。没有改变初始质量，也没有用 F/C 拟合选择替代映射。

这个反例针对只给有限点轨迹和初始质量的运动学反问题，不宣称替代映射还满足同一 Becker 动量/能量方程。它表明：如果不提供物质边界轨迹、连接信息或额外闭合假设，真实单元体积不能被点轨迹唯一识别。
